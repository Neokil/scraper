API docs by Redocly

Browser Scraping API (0.1.0)

Download OpenAPI specification:

Central API for interactive, headed Chromium sessions. This service is designed for a trusted LAN. The evaluate endpoint executes arbitrary JavaScript in the current page and must not be exposed to untrusted networks.
